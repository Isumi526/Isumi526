## 👋 About Me

中小企業向けに **AI開発・業務自動化サービス「全力AIラボ」** を運営しています。
「業務を、人に頼り続けない会社をつくる。」をミッションに、AI支援エンジニアリングで
システム開発の障壁を下げ、リアルな現場の業務をプロダクトに落とし込んでいます。

直近では、建設業向けに **施工台帳AIツール**(LIFF + Supabase + 自動PDF生成 + リアルタイム集計管理画面)を

AI(Claude / Cursor)をフル活用した開発スタイルで、設計から実装までを高速に回せるのが強みです。
